# 节点右键菜单功能

## 功能概述

在 MOC 索引视图的分支图中，右键点击节点可以打开上下文菜单，快速执行常用操作。

## 使用方法

### 打开右键菜单

1. 打开 MOC 文件（在索引视图中）
2. 在分支图中**右键点击**任意节点
3. 在弹出的菜单中选择操作

### 菜单选项

#### 1. ➕ 添加子节点
- **功能**：为当前节点添加一个子节点
- **快捷操作**：自动生成子节点 ID
- **用途**：快速扩展思维树结构

#### 2. 🔗 添加反向连接
- **功能**：创建一个新节点，并建立反向关系
- **关系方向**：新节点 → 当前节点
- **用途**：建立逆向引用关系

#### 3. 📄 打开文件
- **功能**：在当前标签页打开节点对应的笔记
- **快捷键**：等同于直接点击节点

#### 4. 🗂️ 在新标签页打开
- **功能**：在新标签页打开节点对应的笔记
- **快捷键**：等同于 Ctrl + 点击节点

## 功能详解

### 添加子节点

当你选择"添加子节点"时：

1. 自动生成子节点 ID（基于父节点 ID）
2. 打开"添加自由节点"对话框
3. 预设父节点连接
4. 填写节点信息后，新节点会作为子节点添加

**示例：**
- 父节点 ID：`a`
- 生成子节点 ID：`a.1`、`a.2`、`a.3`...

### 添加反向连接

反向连接用于建立逆向引用关系：

**正向连接**：A → B（A 引出 B）
**反向连接**：B → A（B 引用 A）

**使用场景：**
- 建立"被引用"关系
- 创建反向索引
- 建立双向关联

**示例：**
```markdown
# 思维树
- [[量子力学]] `a`
- [[波函数]] `b`

`a` --引出--> `b`  # 正向：量子力学引出波函数
`b` --应用--> `a`  # 反向：波函数应用量子力学
```

## 技术实现

### 事件流程

1. **右键点击节点** → 触发 `cxttap` 事件（Cytoscape）
2. **触发自定义事件** → 触发 `node-contextmenu` 事件
3. **显示菜单** → 使用 Obsidian 的 `Menu` API
4. **执行操作** → 调用相应的方法

### 关键代码

**CytoscapeRenderer.ts** - 监听右键事件：
```typescript
this.cy.on('cxttap', 'node', (evt: any) => {
    const node = evt.target;
    const data = node.data();
    const originalEvent = evt.originalEvent as MouseEvent;
    
    this.container?.dispatchEvent(new CustomEvent('node-contextmenu', {
        detail: {
            node: data.originalNode,
            event: originalEvent,
            position: node.renderedPosition()
        }
    }));
});
```

**IndexView.ts** - 处理右键菜单：
```typescript
branchGraphDiv.addEventListener('node-contextmenu', (event: any) => {
    const { node, event: mouseEvent } = event.detail;
    
    mouseEvent.preventDefault();
    
    const menu = new Menu();
    
    menu.addItem((item) => {
        item.setTitle("➕ 添加子节点")
            .onClick(async () => {
                await this.addChildNodeToMOC(node);
            });
    });
    
    // ... 其他菜单项
    
    menu.showAtMouseEvent(mouseEvent);
});
```

## 与其他功能的关系

### 与双击创建的区别

| 功能 | 双击空白处 | 右键节点 |
|------|-----------|---------|
| 触发位置 | 空白处 | 节点上 |
| 创建类型 | 自由节点 | 子节点/关联节点 |
| 父子关系 | 无 | 有（可选） |
| 位置 | 双击位置 | 自动布局 |

### 与按钮创建的区别

| 功能 | 右键菜单 | 顶部按钮 |
|------|---------|---------|
| 访问方式 | 右键节点 | 点击按钮 |
| 上下文 | 有（当前节点） | 无 |
| 预设信息 | 自动预设父节点 | 需手动选择 |
| 使用场景 | 快速添加关联 | 独立创建 |

## 快捷操作对比

### 节点操作快捷方式

| 操作 | 方式 |
|------|------|
| 打开文件 | 左键点击 / 右键菜单 |
| 新标签页打开 | Ctrl + 左键 / 右键菜单 |
| 添加子节点 | 右键菜单 |
| 添加反向连接 | 右键菜单 |
| 查看预览 | 鼠标悬停 |

### 创建节点快捷方式

| 操作 | 方式 |
|------|------|
| 创建自由节点 | 双击空白处 / 顶部按钮 |
| 创建子节点 | 右键节点 → 添加子节点 |
| 创建关联节点 | 右键节点 → 添加反向连接 |

## 注意事项

1. **右键菜单位置**：菜单会显示在鼠标位置
2. **阻止默认菜单**：会阻止浏览器的默认右键菜单
3. **节点 ID 生成**：子节点 ID 会自动基于父节点生成
4. **关系保存**：反向连接会保存到 MOC 文件的箭头关系中

## 使用建议

### 何时使用右键菜单

- ✅ 需要为现有节点添加子节点
- ✅ 需要建立节点之间的关系
- ✅ 快速访问节点文件
- ✅ 在特定节点上下文中操作

### 何时使用其他方式

- 双击空白处：创建独立的自由节点
- 顶部按钮：创建没有父节点的新节点
- 直接点击：只是打开文件，不需要其他操作
