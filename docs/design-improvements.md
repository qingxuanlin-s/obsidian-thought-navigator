# 视觉设计改进说明

## 核心设计理念

从"工程化"向"现代化、专业化"转变，减少视觉噪音，突出内容本身。

## 改进详情

### 1. 分组的容器化 (Containerization)

**旧设计**：
- 红色虚线框 (`#ef4444` dashed border)
- 感觉像是在圈选错误或警告
- 视觉上过于突兀

**新设计**：
- **半透明深色背景**：`rgba(30, 41, 59, 0.2)` (slate-800/20)
- **大圆角**：`border-radius: 32px` (2rem)
- **背景模糊**：创造物理上的"区域"感
- **柔和文字**：`#94a3b8` (slate-400)

**设计原理**：
- 大圆角是消除工程味的关键
- 半透明背景创造层次感，而不是用线条分割
- 类似 macOS 和现代 UI 的毛玻璃效果

### 2. ID 标签的降噪 (Tag Reduction)

**旧设计**：
- 醒目的深蓝色实心块 (`#5b8fd9` solid background)
- 白色文字 (`#ffffff`)
- 太抢眼，仿佛 ID 比内容还重要

**新设计**：
- **Outline 风格**：`border: 1px solid rgba(71, 85, 105, 0.4)`
- **微着色背景**：`rgba(59, 130, 246, 0.15)` (blue-500/15)
- **柔和文字**：`#94a3b8` (slate-400)
- **背景模糊**：`backdrop-filter: blur(4px)`
- **更小字号**：9px (原 10px)

**设计原理**：
- ID 作为元数据（Metadata）存在
- 既能看清，又不喧宾夺主
- 类似 GitHub 的 tag 设计

### 3. 顶部重音线 (Top Accent Line)

**新增设计**：
- 在节点顶部增加 3px 的蓝色边框
- 颜色：`#5b8fd9` (蓝色)
- 位置：`border-top-width: 3px`

**设计原理**：
- Material Design 3 和现代 SaaS 常用手法
- 在不增加复杂背景的情况下区分卡片类型
- 可以根据节点类型使用不同颜色：
  - 蓝色：方程、核心概念
  - 灰色：扩展、补充内容
  - 绿色：实验、应用

### 主色调
- **蓝色**：`#5b8fd9` - 重音、强调
- **深色背景**：`rgba(30, 41, 59, 0.2)` - 分组容器
- **灰色文字**：`#94a3b8` - 元数据、次要信息

### 透明度使用
- **0.15**：微着色背景（徽章）
- **0.20**：容器背景（分组）
- **0.40**：边框（outline）

## 实现细节

### CSS 属性
```css
/* 分组容器 */
background-color: rgba(30, 41, 59, 0.2);
border-radius: 32px;
backdrop-filter: blur(4px);

/* ID 徽章 */
background-color: rgba(59, 130, 246, 0.15);
border: 1px solid rgba(71, 85, 105, 0.4);
color: #94a3b8;
backdrop-filter: blur(4px);

/* 节点重音线 */
border-top-width: 3px;
border-top-color: #5b8fd9;
```

## 实现状态

### ✅ 已实现
1. **分组容器化**
   - 半透明深色背景：`rgba(30, 41, 59, 0.2)`
   - 移除虚线边框
   - 使用 `round-rectangle` shape 提供圆角效果
   - 柔和文字颜色：`#94a3b8`

2. **ID 徽章降噪**
   - Outline 风格：`border: 1px solid rgba(71, 85, 105, 0.4)`
   - 微着色背景：`rgba(59, 130, 246, 0.15)`
   - 柔和文字：`#94a3b8`
   - 背景模糊：`backdrop-filter: blur(4px)`
   - 更小字号：9px

### ❌ 无法实现（Cytoscape 限制）
1. **自定义 border-radius**
   - Cytoscape 不支持 `border-radius` CSS 属性
   - 只能使用预定义的 shape（如 `round-rectangle`）
   - 无法实现 32px 的大圆角

2. **节点顶部重音线**
   - Cytoscape 不支持 `border-top-width`、`border-top-color` 等单边边框属性
   - 可能的替代方案：使用 HTML 叠加层（类似徽章实现）

### 🔄 技术限制说明
Cytoscape.js 使用 Canvas 渲染，不支持完整的 CSS 规范。只支持特定的样式属性集合。这意味着某些现代 CSS 特性（如单边边框、自定义圆角半径、backdrop-filter 等）无法直接应用于图形元素。

## 未来扩展

### 可配置的重音线颜色
如果使用 HTML 叠加层实现顶部重音线，可以根据节点类型自动分配颜色：
- 方程类：蓝色 `#5b8fd9`
- 定理类：紫色 `#a78bfa`
- 应用类：绿色 `#34d399`
- 扩展类：灰色 `#64748b`

### 分组主题
支持不同的分组主题：
- 默认：深色半透明
- 强调：带颜色的半透明
- 最小：仅边框

### 动画效果
- 悬停时的微妙缩放
- 选中时的脉冲效果
- 平滑的颜色过渡
