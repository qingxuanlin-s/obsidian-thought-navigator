# 添加初始节点功能

## 功能说明

现在可以在 MOC 思维树为空（没有任何节点）的情况下，直接添加第一个初始节点。

## 使用方法

### 1. 在空白 MOC 中添加初始节点

当 MOC 文件中还没有任何节点时：

1. 点击右上角的 **"添加自由节点"** 按钮（➕ 图标）
2. 或者在空白画布上 **双击**
3. 在弹出的对话框中：
   - **Wiki 链接**：输入或搜索要关联的文件名（必填）
   - **节点 ID**：手动输入初始节点 ID（必填，如：`1`, `a`, `1a` 等）
   - 系统会显示提示："当前 MOC 中没有节点，将创建第一个初始节点。"
4. 点击 **"创建"** 按钮

### 2. 在已有节点的 MOC 中添加节点

当 MOC 文件中已经有节点时：

1. 点击右上角的 **"添加自由节点"** 按钮
2. 在弹出的对话框中：
   - **连接到节点**：选择要连接的父节点（可选）
   - **Wiki 链接**：输入或搜索要关联的文件名（必填）
   - **节点 ID**：
     - 如果选择了父节点，系统会自动生成子节点 ID（只读）
     - 如果不选择父节点，可以手动输入节点 ID
   - **连接关系**：描述与父节点的关系（可选）
3. 点击 **"创建"** 按钮

## 节点 ID 生成规则

### 初始节点（无父节点）
- 默认建议 ID：`1`
- 可以手动输入任何有效的 ID（如：`a`, `1a`, `root` 等）

### 子节点（有父节点）
- 自动生成规则：数字和字母间隔
  - 父节点是数字 → 生成字母后缀：`1` → `1.a`, `1.b`, `1.c`...
  - 父节点是字母 → 生成数字后缀：`1.a` → `1.a.1`, `1.a.2`, `1.a.3`...
- 如果生成的 ID 已存在，系统会自动顺延

### 自由节点（无父节点，但已有其他节点）
- 默认建议 ID：`free.1`, `free.2`, `free.3`...
- 可以手动修改为其他 ID

## 技术实现

### 修改的文件

1. **src/modal/addFreeNodeModal.ts**
   - 移除了"没有可用节点时无法添加"的限制
   - 将"连接到节点"从必选改为可选
   - 在没有节点时，允许手动输入节点 ID
   - 优化了验证逻辑，支持三种场景：
     - 有节点且选择了父节点
     - 有节点但未选择父节点
     - 没有节点（创建初始节点）

2. **src/view/indexView.ts**
   - 修改 `saveFreeNodeToMOC` 方法，支持无父节点的情况
   - 修改 `generateNextFreeNodeID` 方法，在没有节点时返回 `"1"` 作为初始 ID
   - 优化了节点插入逻辑，区分有父节点和无父节点的情况

## 用户体验改进

1. **友好的提示信息**
   - 空白 MOC 显示："📝 思维树为空，双击空白处或点击右上角按钮创建第一个节点"
   - 对话框显示："当前 MOC 中没有节点，将创建第一个初始节点。"

2. **灵活的 ID 输入**
   - 初始节点可以自定义 ID，不受限制
   - 子节点自动生成 ID，避免冲突
   - 自由节点使用 `free.X` 格式，易于识别

3. **一致的操作体验**
   - 无论是否有节点，都可以通过相同的按钮添加节点
   - 对话框根据当前状态自动调整显示内容
   - 验证逻辑智能判断，给出准确的错误提示

## 示例场景

### 场景 1：创建第一个节点
```markdown
# 思维树

（空白）
```

操作：点击"添加自由节点"，输入 Wiki 链接 `概念A`，节点 ID `1`

结果：
```markdown
# 思维树
- [[概念A]] `1`
```

### 场景 2：添加子节点
```markdown
# 思维树
- [[概念A]] `1`
```

操作：点击"添加自由节点"，选择父节点 `1`，输入 Wiki 链接 `概念B`

结果：
```markdown
# 思维树
- [[概念A]] `1`
    - [[概念B]] `1.a`
```

### 场景 3：添加自由节点
```markdown
# 思维树
- [[概念A]] `1`
    - [[概念B]] `1.a`
```

操作：点击"添加自由节点"，不选择父节点，输入 Wiki 链接 `概念C`

结果：
```markdown
# 思维树
- [[概念A]] `1`
    - [[概念B]] `1.a`
- [[概念C]] `free.1`
```
