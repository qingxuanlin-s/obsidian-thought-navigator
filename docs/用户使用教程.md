# Thought Tree Navigator 用户使用教程

## 1. 插件简介

Thought Tree Navigator 是一个用于 Obsidian 的卡片盒笔记法思维树插件，核心目标是：

- 把你的笔记组织成可视化「思维树」
- 支持在树上直接增删改节点与关系
- 支持跨领域关联（一个节点关联到其他 MOC）
- 支持局部关系图（邻近、入链/出链）

当前版本：`v0.0.6`（`manifest.json`）

---

## 2. 先理解两个核心视图

1. **思维树视图**（`open zk-index-graph`）
   - 主工作区，用于查看和编辑整棵树。
2. **局部关系视图**（`open zk-local-graph`）
   - 辅助视图，用于查看当前笔记的邻近关系、入链/出链。

---

## 3. 推荐工作流（MOC 模式）

本插件目前最推荐的方式是 **MOC 模式**（Map of Content）。

### 3.1 第二步：创建第一棵思维树

你有两种常用创建方式：

1. 在文件夹右键菜单中选择 `新建思维树`（`New MOC file`）
2. 命令面板执行 `New MOC file` 或 `zk-new-moc-embed`

创建后会得到一个 `.moc` 文件。打开它时，插件会自动用思维树视图接管显示。

### 3.2 第三步：进入树图编辑

打开 `open zk-index-graph` 后，顶部工具栏可以：

- 切换当前 MOC
- 搜索节点
- 居中/返回
- 切换样式（当前主用 `structure`）

图中可进行：

- 拖动节点（位置会自动保存）
- 框选后批量操作（分组、删节点、批量改色）
- 右键节点打开菜单

### 3.3 第四步：节点常用右键操作

在节点右键菜单中，常见操作包括：

- 新增子节点（正向/反向）
- 修改 ID
- 修改颜色
- 关联跨领域节点
- 删除节点

额外能力：

- `Cmd/Ctrl + F`：在思维树内搜索节点
- 在分支视图内可使用撤销（macOS 下为 `Cmd + Z`）
- 直接粘贴图片到树视图（插件会尝试写入附件并生成嵌入节点）

---

## 4. 局部关系视图怎么用

打开命令：`open zk-local-graph`

可在设置中开关：

- 邻近图（父节点、同级节点、子节点）
- 出入链图（inlinks + outlinks）
- 文件类型限制（仅 `.md` 或所有文件）

使用场景：

- 编辑某一张卡片时，快速确认它在整体知识网络中的上下文位置。

---

## 5. 常用命令清单

在命令面板可找到：

1. `open zk-index-graph`：打开思维树视图
2. `open zk-local-graph`：打开局部关系视图
3. `reveal current file in zk-index-graph`：在思维树中定位当前文件
4. `select a main note`：选择主笔记（兼容旧流程）
5. `select an index`：选择关键词（兼容旧流程）
6. `New MOC file`：新建思维树

---

## 6. 设置建议（新用户可直接照抄）

推荐起步配置：
1. `Theme mode`：按系统偏好选 `dark/light`
2. `Theme style`：`modern`
3. `Edge style`：`bezier`
4. `Show note ID in branch view`：开启
5. `文本显示模式`：`id-title`
6. `节点布局风格`：
   - 需要自由拖拽：`free`
   - 更强调自动结构：`auto`

---

## 7. 建议的日常使用节奏

1. 每个主题先新建一个 `.moc` 思维树
2. 先搭一级/二级骨架，再逐步补节点
3. 每次新增卡片时，至少连入一个已有节点
4. 每周做一次跨领域链接（避免知识孤岛）
5. 用局部关系视图复盘单张卡片的上下文

这样你会得到一个可持续生长、可导航、可回顾的卡片盒知识网络。
