工具栏 chip 三层视觉差异化

现状: 三种 class 视觉接近→改造: 显著区分

outlined(主笔记/索引)用透明底 + 实线细边; filled(当前 MOC)用填充底 + 强边 + inset 阴影,昭示"我在这里"; dropdown(视图切换)用透明底 + 虚线边 + ▾,暗示"可切换"。

三种 chip 的视觉语义现在是一眼就分得开的。代码修改集中在 CSS,无需重写组件。

P0 · CSS 修改
2

层级面包屑 · 兄弟切换图标差异化

现状: 兄弟切换 ▾ ≡ 视图切换 ▾→改造: ↕ vs ▾

层级面包屑里"切换兄弟节点"用 chevrons-up-down (↕), 工具栏视图切换保留 chevron-down (▾)。 用户能看出"这个图标是水平切换",而不是又一个下拉。

位置: indexView.ts:3544 把 "\u25BE" 换成 lucide 的 chevrons-up-down 图标即可。

P0 · 1 行修改
3

节点视觉权重 · 三档分级

现状: 所有节点同字号→改造: primary / secondary / detail

在 ext metadata 加 node_visual_weight 字段,字号映射: primary 19px(锚点/根) · secondary 15px(分支头) · detail 12px(细节)。 画布从此有骨架,而不是平铺。

右键菜单加"提升为主节点 / 降为细节"。默认 detail,锚点节点自动 primary。

P1 · 加 ext 字段 + CSS
4

锚点融合 · 金光融入节点边框

现状: 星标贴在角落→改造: 整个节点带金边光晕

保留 ★ 徽章作语义标记,但额外给节点加 box-shadow: 0 0 0 2px var(--gold-border), 0 0 24px -2px gold-glow。 锚点不再像贴纸,而是从节点本体散发出来。

修改: CytoscapeRenderer.ts:4612 锚点 forEach 里同时给目标节点加一条 .anchored class。

P1 · CSS + 1 处选择器
5

长文本节点 · 首行折叠 + 展开

现状: 大段文字挤画布→改造: 2 行预览 + "展开 ↗"

textOnly 节点字符 > N(默认 80)时,用 -webkit-line-clamp: 2 截到两行, 底部加"120 字 · 4 行 / 展开 ↗"。点"展开"复用现有 embed-preview 弹卡基础设施。

画布从此不再有"密密麻麻读不了的灰雾"。

P1 · 复用既有组件
6

Hover 预览 · 让现有能力被看见

现状: Cmd+hover 已生效但无暗示→改造: 节点显式提示

代码已有 hitEl + Obsidian hover-link(CytoscapeRenderer.ts:4334), 但没有 affordance。改造后:hover 时显示节点底部一行 micro-hint "⌘ 预览",松开 Cmd 消失。

第一次使用还在 onboarding hint 里教一遍。

P0 · 加 hover 状态
7

Minimap · 全局导航

现状: 大画布只能拖拽找→改造: 右下角缩略图 + 视口框

用 cytoscape-navigator 扩展(已经在依赖里能加)~50 行接入。 锚点节点在 minimap 里显示金色,普通节点灰色。点击/拖拽视口框跳转。

这是大画布工具的必备件,没有它用户在 50+ 节点时会迷路。

P1 · 新依赖 50 行
8

状态栏 · 行动信息 vs 环境信息分流

现状: 4 类信息平铺→改造: 左行动 / 右环境

左侧 强调需要用户行动的信息(如"3 张到期"配脉冲点 + 橙底); 右侧 是环境状态(反向链接数 / 同步状态 / Flomo)用图标 + tooltip,降级处理。

用户视线一进入状态栏,左边是"该做什么",右边是"在干什么"。两种心智模型分开。

P0 · CSS + DOM 重排

Space ↔ MOC 的视觉关系

消除"画布和抽屉是两个不相关产品"的错觉。
